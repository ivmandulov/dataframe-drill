Reading & inspecting start here

Create / load

print(pd.DataFrame(list_of_dicts)) print(pd.DataFrame({"a": [1, 2], "b": [3, 4]})) print(pd.read_csv("file.csv")) print(pd.read_json("file.json"))

Inspect

print(df.head()) # first 5 rows df.info() # prints directly — no need to wrap print(df.describe()) # numeric summary stats print(df.shape) # (rows, cols) print(df.columns) # column names print(df.dtypes) # per-column type

Select & filter

Column selection

print(df["col"]) # Series print(df[["a", "b"]]) # DataFrame, subset of cols

Row selection

print(df.loc[0]) # by label/index print(df.iloc[0]) # by position print(df.loc[0:2, "a":"c"]) # label slice, INCLUSIVE end print(df.iloc[0:2, 0:2]) # position slice, exclusive end

Boolean filtering

print(df[df["amount"] > 100]) print(df[(df["status"] == "paid") & (df["amount"] > 100)]) # & / | not and/or, parens required print(df[df["region"].isin(["US", "EU"])]) print(df[~df["region"].isin(["US"])]) # negate with ~

Query alternative

print(df.query("amount > 100 and status == 'paid'"))

Transform & create columns

Direct assignment (preferred — vectorized)

df["notional"] = df["price"] * df["qty"] df["flag"] = df["amount"] > 100 print(df)

.apply() — row/element-wise, slower

df["category"] = df["amount"].apply( lambda x: "High" if x >= 2000 else "Low" ) df["total"] = df.apply(lambda row: row["price"] * row["qty"], axis=1) # axis=1 = row-wise print(df)

.map() — Series-to-Series lookup

tax_rates = {"US": 0.07, "EU": 0.20} df["rate"] = df["region"].map(tax_rates).fillna(0) print(df)

np.select / np.where — vectorized if/elif

import numpy as np conditions = [df["revenue"] >= 2000, df["revenue"] >= 1000] choices = ["High", "Medium"] df["tier"] = np.select(conditions, choices, default="Low") print(df)

Missing data

Detect

print(df.isna().sum()) # nulls per column print(df["col"].isna()) # boolean mask

Handle

print(df.fillna(0)) print(df["col"].fillna(df["col"].mean())) print(df.dropna()) # drop rows with any NaN print(df.dropna(subset=["col"])) # only consider this column

GroupBy — the single most-used shape

Single aggregation

print(df.groupby("customer")["amount"].sum()) print(df.groupby("customer")["amount"].agg(["sum", "mean", "count"]))

Named aggregation — multiple cols, clean output

result = df.groupby("customer").agg( total=("amount", "sum"), orders=("amount", "count"), avg=("amount", "mean"), ).reset_index() print(result)

Filter before grouping

print(df[df["status"] == "paid"].groupby("customer")["amount"].sum())

Group then transform back to original shape

# adds a column: each row gets its group's total df["customer_total"] = df.groupby("customer")["amount"].transform("sum") print(df)
reset_index() A groupby result has the group key as the index, not a column — call .reset_index() if you need it back as a normal column (e.g. before merging or sorting on it as a column).

Sort & rank

Sort / top N

print(df.sort_values("amount", ascending=False)) print(df.nlargest(5, "amount")) # top 5, more efficient than sort+head

Rank

df["rank"] = df["amount"].rank(ascending=False, method="min") print(df)

Merge & combine

Merge (SQL join equivalent)

print(pd.merge(orders, customers, on="customer_id", how="left")) print(pd.merge(a, b, left_on="id", right_on="cust_id", how="inner"))

how: inner / left / right / outer — same semantics as SQL.

Concat (stack, not join)

print(pd.concat([df1, df2])) # stack rows print(pd.concat([df1, df2], axis=1)) # stack columns side by side

Pivot

pivot_table — group + reshape in one step

print(pd.pivot_table(df, values="amount", index="customer", columns="month", aggfunc="sum", fill_value=0))

Dates & time series ROITI's actual project is time-series — worth being fluent here

Parse & access

df["date"] = pd.to_datetime(df["date"]) print(df["date"].dt.year) print(df["date"].dt.month) print(df["date"].dt.day_name())

Set as index for time-series ops

df = df.set_index("date") print(df)

Resample — the Pandas equivalent of TimescaleDB's time_bucket()

print(df.resample("1H")["price"].mean()) # hourly average print(df.resample("1D")["volume"].sum()) # daily total

Rolling window

df["rolling_avg"] = df["price"].rolling(window=3).mean() print(df)

Gotchas worth naming out loud if they come up

SettingWithCopyWarning Happens when you assign into a slice that might be a view or a copy — Pandas can't always tell which. Fix by using .loc[] explicitly for the assignment, or call .copy() right after a filter if you intend to modify the result: sub = df[df["x"] > 0].copy().
Chained indexing df[df["x"] > 0]["y"] = 1 may silently fail to modify the original — two separate __getitem__ calls, not one. Use df.loc[df["x"] > 0, "y"] = 1 instead — single, unambiguous operation.
Vectorize before you .apply() A direct column operation (df["a"] + df["b"]) runs in optimized C under the hood; .apply() runs a Python function per row and is much slower. Reach for .apply() only when there's no vectorized way to express the logic — worth saying this explicitly if asked about performance.
NaN != NaN float("nan") == float("nan") is False — never compare for missing values with == None or == np.nan; use .isna().

Pattern Stack → Pandas same shapes, idiomatic Pandas instead of raw loops

The 14 patterns from the earlier prep, translated. If the round is Pandas-based rather than plain-Python, these are the versions to reach for.

Accumulator → sum with a filter

paid_total = df.loc[df["status"] == "paid", "amount"].sum() print(paid_total)

Set → unique / nunique

print(df["customer"].nunique()) electronics_customers = set(df.loc[df["category"] == "Electronics", "customer"]) print(electronics_customers)

Counter → value_counts

print(df["product"].value_counts().idxmax()) # most common print(df["product"].value_counts().head(1))

Group → Aggregate

print(df.groupby("customer")["amount"].sum())

Filter → Aggregate

total = df.loc[(df["product"] == "Laptop") & (df["date"] >= "2025-10-01"), "amount"].sum() print(total)

Derived Metric

df["margin_pct"] = np.where( df["revenue"] > 0, (df["revenue"] - df["cost"]) / df["revenue"] * 100, None, ) print(df)

Previous vs Current

df["growth_pct"] = df["value"].pct_change() * 100 df["prev"] = df["value"].shift(1) print(df)

Sliding Window

df["rolling_avg"] = df["value"].rolling(window=3, min_periods=1).mean() print(df)

Sort → Top N

print(df.groupby("customer")["amount"].sum().nlargest(5))

Sort → Rank

totals = df.groupby("customer")["amount"].sum() print(totals.rank(ascending=False, method="min"))

Metric → Rules → Category

bins = [-float("inf"), 1000, 2000, float("inf")] labels = ["Low", "Medium", "High"] df["category"] = pd.cut(df["revenue"], bins=bins, labels=labels) print(df)

Match → Compare (reconciliation)

merged = pd.merge(system_a, system_b, on="key", suffixes=("_a", "_b"), how="outer") mismatches = merged[merged["value_a"] != merged["value_b"]] print(mismatches)

Multi-Source Merge

order_value = prices.merge(quantities, on="product") order_value["total"] = order_value["price"] * order_value["qty"] print(order_value)

Common interview tasks quick warm-ups, worth running through once before you start

Simple, frequently-asked shapes — smaller and more self-contained than the Pattern Stack above, closer to what a live warm-up question looks like.

Remove duplicate rows

print(df.drop_duplicates()) print(df.drop_duplicates(subset=["order_id"], keep="first"))

Top N per group (not just overall top N)

top_per_customer = ( df.sort_values("amount", ascending=False) .groupby("customer") .head(3) # top 3 orders per customer ) print(top_per_customer)

Reconciliation — rows that differ between two sources

merged = a.merge(b, on="key", suffixes=("_a", "_b"), how="outer", indicator=True) diffs = merged[merged["_merge"] != "both"] # missing on one side print(diffs) mismatches = merged[merged["value_a"] != merged["value_b"]] # present both, differ print(mismatches)

Find gaps in a time series relevant here

df = df.sort_values("time") expected = pd.date_range(df["time"].min(), df["time"].max(), freq="1min") missing = expected.difference(df["time"]) print(missing)

Forward-fill missing values over time

df = df.set_index("time").asfreq("1min") df["price"] = df["price"].ffill() # or .interpolate() print(df)

Long → wide reshape

# one row per (date, metric) -> one row per date, one column per metric print(df.pivot(index="date", columns="metric", values="value"))

Clean a messy text column

df["name"] = df["name"].str.strip().str.lower() df["name"] = df["name"].str.replace(r"\s+", " ", regex=True) print(df)

Two numbers that sum to a target plain-Python warm-up

def two_sum(nums, target): seen = {} for i, n in enumerate(nums): complement = target - n if complement in seen: return (seen[complement], i) seen[n] = i return None print(two_sum([2, 7, 11, 15], 9)) # (0, 1)
